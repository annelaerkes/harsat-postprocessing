
# harsat-postprocessing

<!-- badges: start -->
<!-- badges: end -->

The harsat-postprocessing repo contains a small step by step example on how to 
postprocess the output of the harsat statistical R-package. 
It will be used at the harsat use meeting November 2026 for testing visualizations and github features. 
It includes examples on visualizations with ggplot2 graphs and tables. 
These examples can be used as a basis for creating personalized postprocessing scripts for harsat outputs.
